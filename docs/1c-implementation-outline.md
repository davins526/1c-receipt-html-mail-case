# Граница расширения и изоляция тестирования

Проект описывает дополнительный HTML-слой над штатной массовой рассылкой. Реальные метаданные и BSL из клиентской базы не публикуются.

- Персональные данные формируются **один раз**, при подготовке квитанции; подстановки письма не пересчитывают сумму независимо от PDF.
- HTML-шаблон — отдельно от получения расчётных данных и SMTP-транспорта.
- Тестовая копия базы с отключёнными регламентными заданиями, отправка только в локальный Mailpit и ограничение выборки.
- Расширение для одной клиентской базы применимо только после проверки заимствованных объектов и совместимости; текущий публичный статус — прототип.
- Публичный `demo/render_preview.py` не отправляет сообщения, не имеет доступа к базе и нужен только для проверки экранирования HTML и разметки.
