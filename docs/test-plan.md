# Проверки перед внедрением

- [ ] Отдельная копия БД, регламентные задания отключены.
- [ ] Ограниченный тестовый набор ЛС, ни одной отправки настоящим пользователям.
- [ ] SMTP перенаправлен на Mailpit; проверены адреса назначения.
- [ ] Подстановки: ЛС, адрес, период, итоговая сумма, срок оплаты, контакты.
- [ ] Точное соответствие итоговой суммы письма и PDF из одного источника.
- [ ] Проверены HTML и plain-text fallback, отображение на узком экране, письмо без картинок.
- [ ] Проверена сохранность PDF-вложения и корректное отсутствие повторной массовой отправки.
- [ ] Подтверждена совместимость расширения с конкретной базой и отсутствие воздействия на других клиентов.
- [ ] Только после согласования — отдельное внедрение и контроль.

**Статус этого публичного кейса:** история прототипирования и проверок, а не заявление о завершённой промышленной эксплуатации.
